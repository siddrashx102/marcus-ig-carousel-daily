# Marcus — TikTok Content Format

Account: @marcus.stoic.calm
Niche: stoic mindset / discipline, pain-point angle

## Proven formats (matches reel_1, reel_2 already produced)

1. **Talking-head + voiceover b-roll** — script hooks pain point line 1, resolves by line 4-5. Primary format, already in use.
2. **Text-on-screen + trending audio, no voice** — quote/line reveals synced to beat. Low production, good for fast hook testing.
3. **POV / second-person direct address** — "The version of you who has it together..." Strong retention, feels personal.
4. **Story / personal narrative** — vulnerable open ("There was a year I couldn't sleep...") → lesson close. Builds parasocial trust, drives follows over views.
5. **Rapid-fire list/carousel voiceover** — "3 things nobody tells you about discipline." Easy to batch, algorithm favors listicle hooks.

## Delivery mechanics

- Hook in first 1.5 sec — pain point stated cold, no intro.
- Captions burned in always.
- 15-30 sec sweet spot for this niche.
- Post 1x/day minimum for first 30 days.

## Script skeleton

Pain point → reframe → line worth screenshotting. Rotate topics: sleep, procrastination, confidence, comparison, discipline.
